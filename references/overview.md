# 来源与适用范围

方法来源于 Mike Caulfield 的 [视频](https://www.youtube.com/watch?v=jFiimvVsG1s) 与 [2025-10-13配套文章](https://mikecaulfield.substack.com/p/get-it-in-track-it-down-follow-up)。详细归属与许可范围见仓库中的来源说明。

视频依据为一份英文自动字幕转写，文件标注17:49；未校对音画，最后一句不完整，视频发布日期未知。只覆盖所给正文，未使用附带的自动 Summary，不保证完整视频覆盖。原始转写不随仓库分发。

三个能力对应：
- submit-material：03:42、14:48，原主张或可读图像启动。
- trace-citations：00:00、05:19、06:39、14:48，调查来源并页内定位，命中不等于验证。
- evidence-followup：10:30、12:00、13:30、14:48，改进证据与解释难度。

案例仅为讲者口述演示：普利茅斯岩与登月舱脚垫。数字、物理解释、机构名称和论文未独立核实；讲者在来源定位时承认不确定，解释简化未展示实际结果。见各卡 A1。

SIFT、具体行动和信息环境地图作为背景理解，不扩写完整 SIFT 协议。视频中的工具偏好是录制时示范，不当作当前产品推荐。

输入/输出字段、状态、失败分支、提示模板、重述保留来源条件与避免虚假平衡等，是本项目实现约定，不伪装成作者原有协议。复杂冲突裁决、量化评分和统一停止规则在范围之外。
